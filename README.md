# IoT-Based Environmental Monitoring System Using ESP32

## Project Overview

This project monitors environmental conditions using an ESP32 microcontroller, DHT22 temperature and humidity sensor, and LDR light sensor. The collected sensor data is transmitted through Wi-Fi to the ThingSpeak IoT cloud platform for visualization.

## Objectives

* Monitor temperature and humidity.
* Measure environmental light intensity.
* Establish Wi-Fi connectivity using ESP32.
* Upload sensor readings to ThingSpeak.
* Visualize readings through an IoT dashboard.

## Hardware Components

* ESP32 Development Board
* DHT22 Sensor
* LDR Sensor Module

## Software and Platforms

* Arduino C++
* Wokwi Simulator
* ThingSpeak IoT Cloud
* GitHub

## System Architecture

DHT22 and LDR → ESP32 → Wi-Fi → ThingSpeak Dashboard

## Project Results

The ESP32 successfully reads temperature, humidity and light-level values and uploads the readings to ThingSpeak for monitoring.
